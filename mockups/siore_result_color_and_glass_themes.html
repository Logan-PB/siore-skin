결과 화면 색상 시안 3 + 상담링크 글래시 테마 3

A는 지금 구조 그대로 배경·카드·라인 색만 바꾼 안, B는 상담링크 전체 흐름과 구성을 새로 짠 안입니다. (휴대폰 360px 기준)

A. 결과 화면 배경·색상 조합 시안

피부 위치·고민 프로필 카드와 루틴 카드가 페이지 배경과 한 톤으로 어우러지도록 맞춘 3가지 조합

B1. 로즈 쿼츠 글래스 — "고민 먼저 고르기"

밝은 블러시·라벤더 배경 + 반투명 화이트 유리. 첫 화면에서 고민 6개를 바로 누르고, 3문항만 답하면 결과. 내국인·여성 고객, 카운터 함께 보기에 강함

B2. 미드나잇 오로라 — "30초 스킨 스캔"

다크 네이비 배경 + 핑크·블루 오로라 빛 + 유리 패널. 큰 시작 버튼과 슬라이더형 문진, 결과는 대시보드 타일. 매대 QR로 들어오는 외국인 고객의 시선을 끄는 안

B3. 클리어 랩 — "라인별 입구 + 루틴 카드"

화이트·아이스 블루 배경 + 투명 유리. 첫 화면을 NMN(핑크) / 밸런스(블루) 두 입구로 나누고, 결과는 상자 디자인 루틴 카드로 마무리. 약사 상담·입점 제안용으로 신뢰감이 가장 높은 안

※ 화면의 고민 표시는 자가 문진 기반 경향이며 측정·진단 결과가 아닙니다. 가격·공급조건은 고객 화면에 넣지 않았습니다. 사진은 현재 링크의 공식 제품컷을 사용했습니다.
